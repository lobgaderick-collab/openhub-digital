### MoPay Makes it Easier

Thanks to MoPay, you can now send, receive money, make payments and purchases as well as purchase airtime using MoMo and OM. MoPay has a unique approach that presents the user with a smart and friendly user interface (UI) which lets you carry out same operations in an easily.

With it, you don’t need to jot or copy contact information. You have the possibility to select contacts from your phone-book to send money or buy airtime.

### Transaction History

With this app, you don’t need to bother about copying or printing out your transaction history each time. The mobile money app comes with features that keeps a history of your transactions with precise time, date and status.

### QR Code Scan

MoPay’s QR Code Scan will help users receive payments faster. This is great for shop owners and vendors as it will eliminate the queue time and sort out issues of change. You just need to pay in with the exact amount.

### MoPay 1.0.3 & What’s New

MoPay 1.0.3 is the latest version with last updates done on August 29, 2017. The application was updated to work with the latest API from MTN as well as some bug fixes like the invalid amount issues.

MoPay works with both Orange and MTN network operators in Cameroon. The team plans to expand to other countries very soon.

### Requirements & Download

MoPay requires Android 5.0 and above for it to work.
